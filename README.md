# 🐇 Rabbit Tap

Tap-to-earn игра в стиле Hamster Kombat, но с кроликом. Telegram Mini App +
бэкенд на чистом Node.js (без единой npm-зависимости — используется
встроенный `node:sqlite`).

## Что внутри

- **backend/** — HTTP API + бот, на чистом Node.js 22 (`node:http`, `node:sqlite`, `node:https`, `node:crypto`). Никаких `npm install`.
- **frontend/** — одностраничное Telegram Mini App (HTML/CSS/JS, без сборки).

## Механика

- Тап по кролику → монеты (🥕), по курсу `tapPower` (растёт с уровнем).
- Энергия тратится на тапы (1 за тап) и восстанавливается сама со временем (~3 часа на полный бак).
- Уровень растёт от суммарно заработанных монет — с каждым уровнем растут `tapPower` и макс. энергия.
- У каждого игрока свой прогресс (монеты/энергия/уровень), но все видят друг друга:
  - таблица лидеров (🏆) — топ-20 по монетам;
  - общая статистика сообщества на главном экране (игроков, монет, тапов всего).
- Прогресс хранится в SQLite на сервере, привязан к Telegram ID — не теряется при переустановке.

## Админ-панель (для создателя)

Тот, чей Telegram ID указан в `ADMIN_IDS` (.env), видит на главном экране кнопку
⚙️ рядом с 🏆 — она открывает `admin.html`:

- общая статистика по игре (игроков, монет, тапов, макс. уровень);
- поиск игрока по имени/@username/ID;
- по клику на игрока: выдать монеты/энергию, сбросить прогресс, забанить/разбанить.

Доступ проверяется на сервере по тому же `X-Telegram-Init-Data`, что и обычные
запросы — просто открыть `admin.html` вручную без нужного Telegram ID ничего
не даст, сервер ответит 403. Узнать свой Telegram ID — написать
[@userinfobot](https://t.me/userinfobot).

## Запуск локально

### 1. Создать бота

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. `/newapp` или `/mybots → Bot Settings → Menu Button` чтобы позже привязать Mini App URL.

### 2. Настроить бэкенд

```bash
cd backend
cp .env.example .env
# впишите в .env:
#   BOT_TOKEN=токен_от_BotFather
#   WEBAPP_URL=https://ваш-домен.example.com   (после деплоя фронта)
npm start
```

Сервер поднимется на `http://localhost:3000` и сам раздаёт фронтенд из `../frontend`.

### 3. Запустить бота (отдельный процесс)

```bash
npm run bot
```

Бот отвечает на `/start` кнопкой «Играть», открывающей Mini App по `WEBAPP_URL`.

## Деплой

Telegram Mini App обязательно должен открываться по **HTTPS**-адресу — localhost
не подойдёт для реального использования. Варианты:

- Задеплоить `backend/` целиком (он же раздаёт фронтенд) на любой Node.js-хостинг
  (Render, Railway, VPS + Node 22, etc.) — тогда `WEBAPP_URL` = адрес этого сервера.
- Либо захостить `frontend/` отдельно (Netlify/Vercel/статика) и настроить CORS/URL
  API в `app.js` (переменная `API_BASE`), если бэкенд будет на другом домене.

После деплоя:
1. Обновите `WEBAPP_URL` в `.env` на реальный HTTPS-адрес.
2. В BotFather: `/mybots` → ваш бот → `Bot Settings` → `Menu Button` → укажите тот же URL, чтобы кнопка меню тоже открывала игру.
3. Перезапустите `npm run bot`.

## Требования

- Node.js **22.5+** (нужен встроенный `node:sqlite`, стабилен с Node 22.5; также используется `--env-file`, доступный с Node 20.6+).

## Структура API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/me` | Текущее состояние игрока (создаёт при первом заходе) |
| POST | `/api/tap` | `{ "taps": N }` — применить N тапов (1–200 за запрос) |
| GET | `/api/leaderboard` | Топ-20 игроков по монетам |
| GET | `/api/community` | Публичная сводка: игроков, монет, тапов всего |
| GET | `/api/admin/whoami` | 200 если вызывающий — админ, иначе 403 |
| GET | `/api/admin/stats` | Та же сводка, что и `/api/community`, только для админа |
| GET | `/api/admin/users?search=&limit=&offset=` | Список игроков с деталями |
| POST | `/api/admin/grant` | `{ telegramId, coins, energy }` — выдать ресурсы |
| POST | `/api/admin/reset` | `{ telegramId }` — сбросить прогресс игрока |
| POST | `/api/admin/ban` | `{ telegramId, banned }` — забанить/разбанить |

Админ-эндпоинты защищены отдельно: кроме валидной подписи Telegram ещё
проверяется, что `user.id` есть в `ADMIN_IDS`.

Авторизация — через заголовок `X-Telegram-Init-Data` с `Telegram.WebApp.initData`,
подпись проверяется HMAC-SHA256 по официальной схеме Telegram.

## Баланс игры

Все цифры (стартовая энергия, скорость восстановления, прирост монет за тап,
кривая уровней) вынесены в `backend/src/config.js` — правьте под себя.
